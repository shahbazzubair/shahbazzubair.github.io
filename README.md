## System Overview

Welcome to my professional portfolio. This repository houses the source code for a web application designed with a focus on maintainability, performance, and responsive architecture. It utilizes a JSON-driven content structure, allowing for rapid updates to experience, skills, and projects without requiring deep component refactoring.

The user interface features a custom terminal-inspired aesthetic and a fully responsive, native-feeling horizontal swipe carousel for mobile devices.

## Core Features

*   **Data-Driven UI:** Experience, Projects, and Skills are mapped dynamically from strictly structured JSON files, ensuring clean separation of concerns between logic and content.
*   **Mobile-Optimized UX:** Custom CSS scroll-snapping creates a native horizontal swipe experience for project cards on mobile screens, drastically reducing vertical scroll fatigue.
*   **Serverless Contact:** Integrated with the Web3Forms API to handle direct email transmission without the need for a dedicated backend server or complex SMTP configurations.
*   **Modular Styling:** Built using CSS Modules to ensure scoped styling and prevent global visual leakage.

## Local Initialization

To run this system locally on your machine, ensure you have Node.js installed, then execute the following sequence:

```bash
# 1. Clone the repository
git clone https://github.com/shahbazzubair/shahbazzubair.github.io.git

# 2. Navigate into the directory
cd shahbazzubair.github.io

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
